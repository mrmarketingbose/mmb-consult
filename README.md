# mr.marketingbose — Consultation Booking Page

This repository hosts the **official booking website** for **mr.marketingbose**, designed to help small business owners book personalized marketing consultation calls easily.

---

## 🌟 Overview

This landing page allows users to:
- Understand the problems with their current marketing approach
- Explore how I help them structure a clear, actionable plan
- View testimonials from real clients
- Book a 45-minute ₹499 consultation call via a simple form
- Instantly receive their Google Meet link after booking

---

## 🧱 Tech Stack

- **HTML5 & CSS3** (fully static site)
- **Google Fonts (Poppins)** for typography
- **Hosted via GitHub Pages** (free hosting)

## 🛠 Deployment Steps (GitHub Pages)

1. Go to your repository **Settings → Pages**
2. Under “Build and Deployment”:
   - **Source:** Deploy from a branch  
   - **Branch:** main  
   - **Folder:** /(root)
3. Click **Save**
4. Wait 1–5 minutes — your page will go live at:  
   `https://mrmarketingbose.github.io/mmb-consult/`

---

## ⚠️ Important Notes

- Ensure the `index.html` file is located in the **root folder** of your repository.
- Keep the filename lowercase (`index.html`) for GitHub Pages compatibility.
- File and folder names are **case-sensitive** on GitHub.
- Booking is **non-refundable** once submitted.
